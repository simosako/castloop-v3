# Migration and restore

For custom-domain migration, first configure the delivery bucket domain and cache, the management zone-purge credential, and matching custom origins in both Workers. Publish at least one Episode so the preflight can check an existing MP3 with HEAD and a one-byte range. `castloop delivery migrate <show> --to <https-origin>` asks for confirmation and submits a revision-bound change. The server checks custom-domain access, cache status and purge access before accepting it. It writes the full new feed, purges affected caches and commits the new origin before workers.dev starts returning per-Show 301 redirects. MP3 object keys and Episode GUIDs stay unchanged.

Use `castloop check --show <show>` to inspect an incomplete migration and `castloop recover <show>` to retry from current accepted intent. `castloop delivery rollback <show>` confirms a return to the preceding committed origin and regenerates the feed. Clients or directories can cache 301 redirects beyond rollback; keep the prior custom domain available while addressing those clients. Real DNS, cache, range and rollback behavior still require disposable-account tests.

`castloop export <file>` stores metadata, identities, publication state and object references. It does not contain audio or artwork; archive the referenced private R2 objects independently. An export is per-Show consistent rather than an atomic cross-Show snapshot.

To restore, first ensure all referenced objects exist in the expected installation and retain their identities. Stop and fully withdraw any existing target Show, then run `castloop restore <file> --replace` and confirm. Restoration installs the state with delivery held. `castloop restore-resume <show>` previews validation and scheduling; confirming it rebuilds delivery and arms future reservations. The current and pending origins of an active restored Show must match this installation's configured origins before resume; configure them first if necessary. Missing sources, a running publication, active cleanup claims or an unwithdrawn target prevent restore.
