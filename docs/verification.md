# Verification

The application is under development. These are local observations, not evidence of a deployed service or Free-tier capacity.

## Local checks

The following checks ran on 2026-11-08 using Bun 1.4.4, Wrangler 4.158.0 and the versions in `bun.lock`:

- `bun run test:domain`: strict metadata schemas, Temporal offsets and daylight-saving gaps/overlaps, RSS rendering, HTML restrictions, readiness and protocol fingerprints.
- `bun run test:cli`: standalone binary draft creation, TOML preflight, pull conflict/backup helpers, media rejection and generated JPEG/PNG cover inspection. Remote pull and push are not implemented.
- `bun run test:workers`: Cloudflare's local Workers runtime exercised shared TOML/time code, SQLite initialization and per-object isolation, plus SQL and alarm rollback/commit in the same transaction. This does not connect to an account.
- `bun run typecheck` and `bun run build:cli`: TypeScript checking, generated Worker binding types and a local standalone CLI build. Only local development commands are implemented.

A generated one-second MP3 was inspected locally to check format, duration, size and SHA-256. The audio and cover inspection modules have also been compiled into a standalone Bun executable; the upload commands that will use them are not implemented yet.

The selected compatibility date is `2026-11-04`, the latest date accepted by the installed local runtime at the time of testing. Type generation and Workers tests start a local loopback server. The Worker binding declaration is generated by `bun run types:worker` and is not committed.

## Outstanding

The management API, direct R2 upload, publication, delivery and the remaining CLI commands still need implementation and integration tests. Cache and range behavior, R2 CopyObject, scheduled publication, failure recovery, CPU/memory limits, custom-domain migration and deployed behavior have not been verified. No Cloudflare resources have been created or modified.
